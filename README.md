# El Cid playthrough: Two Iberias, 1094

An interactive map comparing Iberia and northern Morocco on 15 June 1094, the day the historical El Cid took Valencia, with the same day at the end of a 94-turn playthrough of Nuño Sempere's El Cid wargame (1081 to 1094).

Live page: https://williamhackspeare.github.io/el-cid-playthrough/

The page is a single self-contained HTML file. The historical side draws on 180 researched strongholds with sources listed per stronghold; the game side comes from the game narrator's reports. Frontiers are modelled from stronghold holdings over terrain (ETOPO elevation, geoBoundaries units), not traced from an atlas.
